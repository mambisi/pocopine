# Postmortems

Write-ups of bugs that were subtle, expensive, or touched multiple
layers. The goal isn't blame — it's **invariants new contributors can
check against** so the same class of bug doesn't land twice.

Each file is dated and names the component + failure mode:
`YYYY-MM-DD-<area>-<short-name>.md`.
