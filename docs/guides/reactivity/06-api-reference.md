# Reactivity API reference

Generated from the `pocopine-core` source at build time — signatures and
doc-comments for the public reactive API, grouped by module. It never drifts
from the code because the docs build re-extracts it on every render.

For guided, example-driven coverage start with
[Essentials](./01-essentials.md) and [Utilities](./02-utilities.md); this page
is the exhaustive index. Everything here is re-exported from `pocopine` — the
everyday set lands in `pocopine::prelude::*`, the rest is `pocopine::<name>` or
a module path like `pocopine::tick` / `pocopine::timers` / `pocopine::refs`.
