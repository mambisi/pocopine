# ProseMirror Core Parity Ledger

Local references live under `./tmp/ProseMirror/`.

## Schema spec surface

`NodeSpec` and `MarkSpec` now expose upstream's structural metadata:
`defining_for_content` / `defining_as_context` (plus the `defining` shortcut),
`code`, `whitespace` (Normal | Pre), `non_selectable`, `isolating`,
`linebreak_replacement`, per-attribute `attr(name, default)` /
`required_attr(name)` with `AttributeSpec` defaults filled in at construction
time, and `MarkPolicy` (`All` | `None` | named set). `schema_basic` now flags
`blockquote`, `code_block`, and `list_item` as defining_for_content,
`code_block` as `code` + `whitespace(Pre)`, and `hard_break` as
`linebreak_replacement` (when used in a non-default schema). The Rust-shaped
surface includes everything upstream `NodeSpec`/`MarkSpec`/`AttributeSpec`
expose except `parseDOM`/`toDOM` (deliberately skipped — model-only crate).

## Commands

- `prosemirror-commands/src/commands.ts`, `prosemirror-commands/test/test-commands.ts`, and the `wrapInList` path from `prosemirror-schema-list`: partial. Pine ports the selection commands (`delete_selection`, `select_all`, `select_parent_node`, `select_textblock_start`, `select_textblock_end`), block-structural commands (`lift`, `lift_empty_block`, `join_up`, `join_down`, `split_block`), backward/forward join + select-node (`join_backward`, `join_forward`, `join_textblock_backward`, `join_textblock_forward`, `select_node_backward`, `select_node_forward` — model-only paths matching PM's no-view fallback), and the workhorse formatting commands (`wrap_in`, `wrap_in_list`, `set_block_type`, `toggle_mark`) together with the `chain_commands` combinator. Not yet ported: `newline_in_code`, `exit_code`, `create_paragraph_near`, `split_block_as`, `split_block_keep_marks`, `auto_join`, `base_keymap`. The `Command` trait collapses PM's `(state, dispatch, view) => boolean` to `(state) -> Option<Transaction>`; commands compose via `chain_commands(vec![...])`.

## History

- `prosemirror-history/src/history.ts` and `prosemirror-history/test/test-history.ts`: partial. Pine ships an `history` module with the `history_plugin()`, `undo()` / `redo()` commands, and `undo_depth(state)` / `redo_depth(state)` predicates. Each non-history transaction lands one event on the `done` branch (the inverted steps + the selection at the start of the transaction); undo pops from `done`, applies the inverted steps in reverse, restores the recorded selection, and pushes the inverse event onto `undone`. Redo is symmetric. New edits clear the `undone` branch. Not yet ported: PM's branch compression (`max_empty_items`), inter-transaction event merging (`newGroupDelay` / `time` thresholds), `close_history` to force a new event, and the `preserveItems` collab-rebase remapping. Plugin state is stored as JSON via `Step::to_json` round-trips so it serializes with the rest of the editor state.
