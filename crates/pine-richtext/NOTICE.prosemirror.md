# ProseMirror Attribution

`pine-richtext` is a Rust-native implementation inspired by the core
ProseMirror packages:

- `prosemirror-model`
- `prosemirror-transform`
- `prosemirror-state`
- `prosemirror-schema-basic`

The ProseMirror project is distributed under the MIT license. Milestone 1 uses
ProseMirror's public behavior and source layout as an implementation reference;
the Rust crate is not a vendored copy of the JavaScript packages.

Reference checkouts under `/tmp/prosemirror/*`, when present during
development, are scratch material and are intentionally ignored by the
repository.
