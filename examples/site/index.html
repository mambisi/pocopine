Write the whole app in Rust.

pocopine is a Rust/WASM framework. Component templates, shared stores, and server functions — one codebase, two compile targets, zero JavaScript glue.

§ 03What's in the box

Components

Custom element tags

#[component] derives the scope, registers a <kebab-name> tag, and binds props from HTML attributes straight onto Rust fields. Templates are plain HTML, not a DSL.

Stores

Reactive singletons

#[store] gives you a one-per-app struct readable from templates via $store.name.field and from Rust via pocopine::store::<T>().update(|s| …). Same reactivity engine.

Server

Typed REST bindings

#[server] async fn foo(a: A) -> Result<R, _> compiles twice: a fetch stub on wasm32 and an axum route on the host. One signature, no schema file, no JSON hand-plumbing.

§ 04Get started

While the crate is pre-release, clone and run an example directly. The CLI auto-detects whether a project declares a server binary and dev-serves accordingly.

  1. git clone https://github.com/pocopine/pocopine Pull the repo — examples live in examples/.
  2. cargo run -p pocopine-cli -- dev --path examples/counter Static example → http://localhost:5243.
  3. cargo run -p pocopine-cli -- dev --path examples/blog Full stack + #[server] → http://localhost:3000.
